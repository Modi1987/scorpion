## About

This folder contains the Arduino source code. The key file included is:

- [ESP32_MPU_SERIAL.ino](./ESP32_MPU_SERIAL/ESP32_MPU_SERIAL.ino): This is an Arduino sketch for the ESP32. It reads data from an MPU6050 sensor, performs filtering, and streams quaternion (orientation), gyroscope and gravity measurements over serial to a device connected over USB.
